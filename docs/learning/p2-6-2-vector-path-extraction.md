# LandOS Learning Guide: Digital PDF Vector Path Extraction Engine (Phase P2.6.2 Production Grade)

## 2. Mathematical Transformation Matrix & Graphics State Stack

Engineering PDFs generated by AutoCAD, Civil 3D, or MicroStation frequently apply transformation matrices (`cm`) to position, scale, and rotate drawing blocks:

### 2D Affine Transformation Matrix ($a, b, c, d, e, f$):
Every raw coordinate $[x, y]$ is mapped into page space before primitive construction:
$$x' = a \cdot x + c \cdot y + e$$
$$y' = b \cdot x + d \cdot y + f$$

### Graphics State Stack (`q` / `Q`):
- `q`: Pushes the current active transformation matrix, line width, stroke color, and fill color onto the state stack.
- `Q`: Pops and restores the previous graphics state frame.

## 3. PDF Drawing Operators & Primitive Mapping

| Operator | Full PDF Command Name | Purpose | Output Primitive Type |
|---|---|---|---|
| `q` | `gsave` | Pushes current graphics state onto stack | State frame push |
| `Q` | `grestore` | Pops previous graphics state from stack | State frame pop |
| `cm` | `concat` | Concatenates matrix $M$ to current transformation matrix | CTM update |
| `m` | `moveto` | Begins a new subpath at transformed point $(x', y')$ | Point accumulator |
| `l` | `lineto` | Appends line segment to transformed point $(x', y')$ | `LINE` / `POLYLINE` |
| `c` / `v` / `y` | `curveto` | Appends Bezier curve to transformed point $(x', y')$ | `CURVE` |
| `re` | `rectangle` | Constructs closed rectangle at $(x, y, w, h)$ | `RECTANGLE` |
| `h` | `closepath` | Closes subpath with a line segment to `moveto` | `closed = True` |
| `W` / `W*` | `clip` | Flags current path as a Clipping Path | `isClippingPath = True` |
| `S` / `s` / `f` / `F` / `b` | `stroke` / `fill` | Paints subpath and flushes primitive | `CLOSED_POLYGON` / `LINE` |
