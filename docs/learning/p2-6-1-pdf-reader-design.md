# LandOS Learning Guide: Digital PDF Reader & Stream Inspector (Phase P2.6.1)

**Learning Objective:** Understand how LandOS inspects vector and raster PDF blueprint files using `PDFReader` (`pypdf`), how entity provenance attributes (`id`, `pageNumber`, `source`, `confidence`) are preserved, and why PDF stream reading is isolated from vector path extraction (Phase P2.6.2).

## 2. Why PDF Reading is Isolated from Vector Path Extraction

1. **Failure Isolation:** Reading PDF page dictionaries, media box dimensions, font tables, and text previews is a lightweight, deterministic operation. Keeping it independent ensures that corrupted vector path operators in a single page do not crash the entire file opening step.
2. **Provenance & Page Spatial Context:** Before extracting vector lines or OCR labels, every extracted element needs an explicit spatial page context (`pageNumber`, `widthPt`, `heightPt`, `widthInches`, `heightInches`).
3. **Artifact Persistence:** Persisting `PDF_RAW_STREAM_METADATA` to PostgreSQL `layout_processing_artifacts` allows downstream pipeline stages to read PDF page dimensions and font metadata directly without re-opening the raw disk file.

```json
{
  "filePath": "uploads/projects/e54a89b2-69da-45e4-b073-60d2f59f1a3f/layouts/1ae70eab_blueprint.pdf",
  "fileSizeBytes": 3450000,

```
